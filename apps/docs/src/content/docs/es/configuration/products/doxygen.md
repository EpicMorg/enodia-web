Lee qué Doxygen generó un sitio de documentación. Cada página HTML que
escribe Doxygen lo indica (`<meta name="generator" content="Doxygen
1.19.0"/>`, `<!-- Generated by Doxygen 1.19.0 -->` y el pie de página), y
la sonda toma la versión de los dos primeros. La página que se lee es `/`,
salvo que el `path` del destino indique otra cosa. El esquema por defecto
es `https`.

```yaml
targets:
  - id: api-docs
    product: doxygen
    address: https://docs.example.com
    path: /docs/        # opcional, cuando el sitio no se sirve en /
```

## Una herramienta de compilación, no un servidor

No hay ningún servidor de Doxygen al que preguntar: la versión registrada
es aquella con la que la documentación se **compiló por última vez**, que
es justo lo que delata una cadena de compilación de documentación
desactualizada. Un sitio de documentación detrás de SSO (por ejemplo, una
página de inicio de sesión de oauth2-proxy) no muestra ninguna marca y
falla como no compatible; para un sitio detrás de HTTP Basic, configure
una credencial (más abajo).

## Autenticación

Opcional: solo para un sitio detrás de HTTP Basic. `basic` es el único
tipo aceptado; desde la 2.2.0, cualquier otro tipo es un error de
configuración (consulte
[Configuración → Credenciales](/es/configuration/#credenciales)).

```yaml
credentials:
  docs-basic:
    kind: basic
    username: reader
    password: "${DOCS_PASSWORD}"
```

## Campos registrados

Solo `version`: p. ej. `1.19.0`; esta sonda no registra ningún campo
`extra`.

## Correlación de CVE

Se contrasta con NVD cuando hay configurado un [bloque `cve:`](/es/cve/).

## Resolvedor del ciclo de vida

`github:doxygen/doxygen`: endoflife.date no tiene un calendario de Doxygen
(404 confirmado), por lo que se resuelve contra GitHub Releases: solo la
última etiqueta publicada que no sea prerelease, sin fechas
eol/support/lts (GitHub no tiene opinión sobre la política de ciclo de
vida, solo sobre «cuál es la última versión»). Doxygen etiqueta sus
versiones como `Release_1_18_0`; desde la 2.2.0, el resolvedor `github`
lee esa forma como `1.18.0`.
