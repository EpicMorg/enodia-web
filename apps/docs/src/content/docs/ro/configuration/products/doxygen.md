Citește ce versiune de Doxygen a generat un site de documentație. Fiecare
pagină HTML scrisă de Doxygen o spune — `<meta name="generator" content="Doxygen
1.19.0"/>`, `<!-- Generated by Doxygen 1.19.0 -->` și subsolul — iar sonda
ia versiunea din primele două. Pagina citită este `/`, cu excepția cazului
în care `path` al țintei indică altceva. Schema implicită este `https`.

```yaml
targets:
  - id: api-docs
    product: doxygen
    address: https://docs.example.com
    path: /docs/        # opțional, când site-ul nu este servit la /
```

## Un instrument de build, nu un server

Nu există un server Doxygen pe care să-l interogați: versiunea înregistrată
este cea cu care documentația a fost **generată ultima dată** — exact ceea
ce semnalează un pipeline de documentație învechit. Un site de documentație
din spatele unui SSO (de exemplu, o pagină de autentificare oauth2-proxy)
nu afișează niciun marcaj și eșuează ca neacceptat; pentru un site din
spatele HTTP Basic, configurați o credențială (mai jos).

## Autentificare

Opțională — doar pentru un site din spatele HTTP Basic. `basic` este
singurul tip acceptat; începând cu 2.2.0, orice alt tip este o eroare de
configurare (consultați
[Configurare → Credențiale](/ro/configuration/#credențiale)).

```yaml
credentials:
  docs-basic:
    kind: basic
    username: reader
    password: "${DOCS_PASSWORD}"
```

## Câmpuri înregistrate

Doar `version` — de exemplu `1.19.0`; această sondă nu înregistrează
niciun câmp `extra`.

## Corelare CVE

Se corelează cu NVD atunci când este configurat un [bloc `cve:`](/ro/cve/).

## Rezolvatorul ciclului de viață

`github:doxygen/doxygen` — endoflife.date nu are un calendar pentru
Doxygen (404 confirmat), așa că rezolvarea se face în schimb pe baza
GitHub Releases: doar cel mai recent tag publicat care nu este prerelease,
fără date eol/support/lts (GitHub nu are nicio opinie despre politica
ciclului de viață, doar despre „care este cea mai recentă versiune”).
Doxygen își etichetează lansările sub forma `Release_1_18_0`; începând cu
2.2.0, rezolvatorul `github` citește această formă ca `1.18.0`.
