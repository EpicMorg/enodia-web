Аварийный выход для всего, у чего нет отдельной пробы — самописный блок
`parser:` вместо вкомпилированной Go-логики. Полный список полей,
замороженный словарь `json`/`xml`/`header`/`plaintext`/`regex` и
примечание про написание поля `clean_regex` живут в
[Конфигурации → Generic-проба](/ru/configuration/#generic-проба); эта
страница нужна только для того, чтобы `generic` появился в боковом меню
рядом с остальными 86 продуктами.

```yaml
targets:
  - id: in-house-api
    product: generic
    address: https://internal.example.com
    parser:
      type: regex
      regex: 'v(\d+\.\d+\.\d+)'
```

## Аутентификация

Принимаются `none`, `bearer`, `token-header` и `basic` — то, что
ожидает ваш внутренний сервис.

## Резолвер жизненного цикла

Отсутствует — у самописного таргета по определению нет календаря, по
которому его можно было бы искать. Не нашли свой продукт среди 28
выделенных проб? См. [Поддерживаемые продукты](/ru/products/#не-нашли-свой-продукт)
для двух вариантов: этот аварийный выход или запрос новой пробы.
