Читает версию из заголовка собственной **страницы статистики** HAProxy —
у HAProxy нет эндпоинта версии, и, в отличие от nginx, он вообще не
выставляет заголовок `Server`, идентифицирующий себя, по умолчанию.

```yaml
targets:
  - id: haproxy-main
    product: haproxy
    address: https://haproxy.example.com
```

`/stats` — путь этой пробы по умолчанию; указывайте `path:` явно, только
если ваша страница статистики смонтирована в другом месте.

## Страница статистики должна быть включена

Подтверждено вживую на реальном контейнере `haproxy:3.0`: страница
статистики (`stats enable` в конфиге самого HAProxy; **не включена по
умолчанию**) — единственная анонимная поверхность, которая вообще несёт
версию — у экспорта статистики `;csv` нет столбца версии нигде во всех
~140 столбцах заголовка, поэтому эта проба читает именно HTML-форму.

## Аутентификация

Опционально. `stats auth user:pass` (собственная директива конфига
HAProxy для этой страницы) — обычная HTTP Basic:

```yaml
credentials:
  haproxy-stats:
    kind: basic
    username: admin
    password: "${HAPROXY_STATS_PASSWORD}"
```

## Записываемые поля

Только `version` — эта проба не записывает никаких полей `extra`.

## Резолвер жизненного цикла

`endoflife:haproxy`.
