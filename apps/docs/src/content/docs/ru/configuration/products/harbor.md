Читает `GET /api/v2.0/systeminfo`.

```yaml
targets:
  - id: harbor-main
    product: harbor
    address: https://harbor.example.com
```

## Аутентификация

Опционально. Подтверждено вживую на реальном стеке `goharbor/harbor`
v2.12.2: `harbor_version` возвращается вообще без credentials на любой
текущей выпущенной версии — неверные или выдуманные credentials молча
трактуются как анонимный запрос, а не отвечают `401`; этот эндпоинт
вообще никогда не отклоняет запрос.

:::note[Стоит следить за изменениями в апстриме]
Собственный код Harbor (по состоянию на версию, для которой проверялась
эта проба) уже прячет `harbor_version` за проверкой аутентифицированной
сессии в основной ветке, ещё не выпущенной на момент написания — то
есть движется к тому, что будущий релиз потребует credentials для
этого поля. `basic` уже предлагается здесь на этот случай:

```yaml
credentials:
  harbor-admin:
    kind: basic
    username: admin
    password: "${HARBOR_PASSWORD}"
```
:::

## Записываемые поля

Только `version` — эта проба не записывает никаких полей `extra`.

## Резолвер жизненного цикла

`endoflife:harbor`.
