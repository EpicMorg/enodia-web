Читает версию, которую query-service Jaeger (компонент, отдающий UI,
порт 16686 по умолчанию) встраивает в собственный `index.html` через
подстановку на этапе сборки — отдельного API версии не существует.

```yaml
targets:
  - id: jaeger-main
    product: jaeger
    address: https://jaeger.example.com
```

## Аутентификация

Отсутствует — у Jaeger вообще нет собственной аутентификации. Установка
за обратным прокси или SSO-шлюзом (oauth2-proxy — частый реальный выбор)
отвечает редиректом в собственный флоу входа этого шлюза вместо HTML
Jaeger, что проявляется как ошибка этой пробы «JAEGER_VERSION не
найден» — это не то, что проба способна пройти сама, та же ситуация,
что и у продукта с формой входа.

## Записываемые поля

Только `version` — эта проба не записывает никаких полей `extra`.

## Резолвер жизненного цикла

`endoflife:jaeger`.
