---
title: memcached
description: Настройка enodia для опроса memcached.
---

Проба на сыром TCP через текстовый протокол, не HTTP — `address` это
`host` или `host:port`, без схемы. Порт по умолчанию — `11211`, если не
указан. Отправляет `version` и читает однострочный ответ
`VERSION 1.6.45`.

```yaml
targets:
  - id: memcached-01
    product: memcached
    address: cache.example.com:11211
```

## Аутентификация

Отсутствует — в текстовом протоколе нет аутентификации. Сервер,
запущенный с SASL (`-S`), говорит только на бинарном протоколе и
отвечает на текстовую команду ошибкой; это сообщается как «не
поддерживается», без попыток угадать.

## Записываемые поля

Только `version` — например, `1.6.45`. Эта проба не записывает никаких
полей `extra`.

## Сопоставление с CVE

Сверяется с NVD и БДУ ФСТЭК, если настроен [блок `cve:`](/ru/cve/).

## Резолвер жизненного цикла

`endoflife:memcached`.
