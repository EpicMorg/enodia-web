Проба на сыром TCP, не HTTP — `address` это `host` или `host:port`, без
схемы `https://`/`http://` (предупреждать о её отсутствии тут не о чем;
см. [Конфигурацию](/ru/configuration/#targets)). Порт по умолчанию —
`3306`, если не указан.

Запрос вообще не отправляется: MySQL сообщает свою версию сама, без
запроса, в начальном handshake-пакете, ещё до какого-либо шага
аутентификации — поэтому этой пробе никогда не нужен credential, чтобы
её увидеть.

```yaml
targets:
  - id: mysql-main
    product: mysql
    address: db.example.com:3306
```

## Аутентификация

Отсутствует — версия читается прямо из handshake, ещё до точки, где
credential вообще имел бы значение.

## MariaDB — другой продукт

MariaDB маскирует свою настоящую версию префиксом `5.5.5-` для
MySQL-клиентов, которые появились раньше собственной схемы версий
MariaDB — это по-прежнему верно на актуальном образе MariaDB 10.11.
`product: mysql`, указанный на сервер MariaDB, обнаруживает это и
**намеренно отказывает**, называя в ошибке настоящую версию MariaDB, а
не молча записывая её как факт про MySQL. Отдельной пробы `mariadb` пока
нет — это жёсткий стоп, а не то, что сегодня можно обойти через
[generic-пробу](/ru/configuration/products/generic/).

## Резолвер жизненного цикла

`endoflife:mysql`.
