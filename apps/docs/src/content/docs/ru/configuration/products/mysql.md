Проба на сыром TCP, не HTTP — `address` это `host` или `host:port`, без
схемы `https://`/`http://` (предупреждать о её отсутствии тут не о чем;
см. [Конфигурацию](/ru/configuration/#targets)). Порт по умолчанию —
`3306`, если не указан.

Запрос вообще не отправляется: MySQL сообщает свою версию сама, без
запроса, в начальном handshake-пакете, ещё до какого-либо шага
аутентификации — поэтому этой пробе никогда не нужен credential, чтобы
её увидеть.

```yaml
targets:
  - id: mysql-main
    product: mysql
    address: db.example.com:3306
```

## Аутентификация

Отсутствует — версия читается прямо из handshake, ещё до точки, где
credential вообще имел бы значение.

## MariaDB — другой продукт

MariaDB выдаёт себя версией в handshake: MariaDB 10.x маскирует её
префиксом `5.5.5-` для старых MySQL-клиентов
(`5.5.5-10.11.19-MariaDB-ubu2204`), а MariaDB 11.0+ присылает её без
маски, но с тегом (`11.4.13-MariaDB-ubu2404`). `product: mysql`,
указанный на сервер MariaDB, распознаёт оба вида и **намеренно
отказывает**, называя в ошибке настоящую версию MariaDB, а
не молча записывая её как факт про MySQL. Начиная с 2.1, у MariaDB есть
своя проба — для неё используйте
[`product: mariadb`](/ru/configuration/products/mariadb/).

:::caution[MariaDB 11.0+ до 2.1.1]
До 2.1.0 включительно распознавалась только маска `5.5.5-`, поэтому
сервер MariaDB 11.0+ за таргетом `product: mysql` записывался **как
MySQL** и сверялся с жизненным циклом MySQL. Начиная с 2.1.1 такой
таргет вместо этого откажет — переключите его на `product: mariadb`.
:::
