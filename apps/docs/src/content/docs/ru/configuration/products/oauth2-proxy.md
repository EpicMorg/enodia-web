Читает версию, проставленную в футере `/oauth2/sign_in`. У oauth2-proxy
вообще нет JSON-эндпоинта версии — страница входа единственная
анонимная поверхность (она обязана рендериться ещё до появления
какой-либо сессии), и её шаблон по умолчанию печатает версию прямо в
текст футера.

```yaml
targets:
  - id: oauth2-proxy-main
    product: oauth2-proxy
    address: https://auth.example.com
```

## Аутентификация

Отсутствует — подтверждено вживую на реальном контейнере
`oauth2-proxy/oauth2-proxy` со страницей по умолчанию.

## Флаг `--footer` может скрыть версию

Собственный флаг установки `--footer` может заменить или скрыть (`-`)
всю эту строку — анонимного запасного варианта в этом случае нет. Это
подтверждённый продукт с версией, скрытой собственной настройкой
установки, а не ошибка пробы.

## Записываемые поля

Только `version` — эта проба не записывает никаких полей `extra`.

## Резолвер жизненного цикла

`github:oauth2-proxy/oauth2-proxy` — у endoflife.date пока нет
календаря, поэтому резолвинг идёт через GitHub Releases: только
последний опубликованный, не pre-release тег, без данных по
eol/support/lts.
