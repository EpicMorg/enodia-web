---
title: ProFTPD
description: Настройка enodia для опроса ProFTPD.
---

Проба на сыром TCP, не HTTP — `address` это `host` или `host:port`, без
схемы. Порт по умолчанию — `21`, если не указан. Читает приветствие FTP
(ответ `220` из RFC 959), которое любой сервер отправляет без запроса
сразу после подключения, и ищет в нём версию.

```yaml
targets:
  - id: ftp-main
    product: proftpd
    address: ftp.example.com:21
```

## Аутентификация

Отсутствует — приветствие отправляется ещё до какого-либо шага
аутентификации.

## У настройки по умолчанию версии вообще нет

Без настроенной директивы `ServerIdent` — а это и есть реальное
поведение по умолчанию, подтверждено вживую и на реальном
продакшн-хосте, и на свежем контейнере `instantlinux/proftpd` —
приветствие выглядит как `"ProFTPD Server (<ServerName>) [<address>]"`,
без версии вообще. Версия появляется, только если администратор явно
настроил `ServerIdent on "... %{version} ..."` — тоже подтверждено
вживую: `"ProFTPD 1.3.9c ready at 127.0.0.1"`. Так что случай «версия не
найдена» у этой пробы — обычный, а не исключение.

## Записываемые поля

Только `version` — эта проба не записывает никаких полей `extra`.

## Резолвер жизненного цикла

`endoflife:proftpd`.
