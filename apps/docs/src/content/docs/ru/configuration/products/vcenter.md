---
title: vCenter Server
description: Настройка enodia для опроса VMware vCenter Server.
---

Читает `GET /sdk/vimServiceVersions.xml` — SOAP-документ vCenter для
определения версии API, не требующий credentials.

```yaml
targets:
  - id: vcenter-main
    product: vcenter
    address: https://vcenter.example.com
```

## Аутентификация

Отсутствует — эндпоинт не принимает никакого credential.

## Что здесь означает «версия»

Записываемое значение (например, `8.0.3.0`) — это версия API `vim25` из
записи пространства имён `urn:vim25` в документе, а не отдельно
отслеживаемая маркетинговая строка сборки. Собственная документация
VMware считает их эквивалентными, и любой сторонний инструмент,
определяющий версию vCenter таким способом, полагается ровно на это
соответствие.

## Записываемые поля

Только `version` — эта проба не записывает никаких полей `extra`.

## Резолвер жизненного цикла

`endoflife:vcenter`.
