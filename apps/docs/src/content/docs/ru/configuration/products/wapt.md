Читает `GET /ping` сервера WAPT (Tranquil IT), который он отдаёт без
сессии.

```yaml
targets:
  - id: wapt-main
    product: wapt
    address: https://wapt.example.com
```

## Какая версия сообщается

`/ping` содержит и `version` (`1.8.2`), и `git_hash`
(`1.8.2.7334-2d15afd9-debian-10-amd64`), который начинается с полного
номера сборки. Если этот номер сборки продолжает `version`, сообщается
именно он — `1.8.2.7334`, а не `1.8.2`. Подтверждено вживую на боевом
сервере WAPT 1.8.2.

## Аутентификация

Отсутствует — эндпоинт не принимает никакого credential.

## Записываемые поля

- `version` — например `1.8.2.7334`
- `extra.edition` — например `community`
- `extra.apiVersion` — например `v3`
- `extra.gitHash` — например `1.8.2.7334-2d15afd9-debian-10-amd64`

## Сопоставление с CVE

Сверяется с NVD, если настроен [блок `cve:`](/ru/cve/).

С учётом редакции: собственная редакция WAPT (`community`/`enterprise`)
уже записана словами NVD и передаётся как есть. Любое другое значение
считается неизвестной редакцией, и тогда сохраняются все находки.

## Резолвер жизненного цикла

Отсутствует — у WAPT нет страницы на endoflife.date (подтверждено 404),
а теги Tranquil IT на GitHub остановились на 1.5; релизы публикуются на
их собственном сайте, который здесь не читает ни один резолвер. Только
инвентаризация.
