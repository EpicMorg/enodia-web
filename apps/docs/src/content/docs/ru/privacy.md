enodia — это утилита командной строки, которую вы запускаете на своей
машине. У неё нет телеметрии, сбора статистики использования, проверки
обновлений и учётной записи. У EpicMorg нет сервера, к которому
обращалась бы enodia, и от неё он ничего не получает.

Эта страница зеркалит собственный
[`PRIVACY.md`](https://github.com/EpicMorg/enodia/blob/master/PRIVACY.md)
enodia.

## Куда подключается enodia

- **Ваши собственные сервисы** — таргеты из вашего `enodia.yaml`, по
  HTTPS, SSH или их собственным протоколам, с теми credentials, которые
  вы настроили, чтобы прочитать их версию (а для Linux-хостов — список
  установленных пакетов).
- **endoflife.date** (`https://endoflife.date/api/...`) — за публичными
  датами релизов и окончания поддержки. В запросе указывается продукт
  (например, `postgresql`); имена хостов, адреса, версии и любые другие
  данные о вашем парке не передаются.
- **GitHub API** (`https://api.github.com/repos/.../releases`,
  `.../tags`) — для продуктов, релизы которых публикуются на GitHub. То
  же самое: в запросе только публичное имя репозитория. Если задан
  `GITHUB_TOKEN`, он отправляется только в GitHub, чтобы поднять лимит
  запросов.
- **Издатели баз CVE** — только когда вы запускаете `enodia cve update`,
  и только те, которые называют ваши записи `cve.*.path`: nvd.nist.gov,
  bdu.fstec.ru, security-tracker.debian.org, издатели OVAL (Canonical,
  Red Hat, AlmaLinux, Oracle, Astra Linux, РЕД ОС),
  secdb.alpinelinux.org, mariadb.com, api.atlassian.com,
  www.postgresql.org и nginx.org. Это обычные скачивания публичных
  файлов; единственное, что они сообщают о вашем парке, — для каких
  релизов ОС и мажорных версий PostgreSQL вы скачиваете данные.

Больше никуда. Все остальные команды только читают файлы CVE с диска —
см. [Сопоставление с CVE](/ru/cve/).

HTML-отчёт загружает Bootstrap с CDN (jsDelivr / cdnjs) **в браузере,
который его открывает**, если задано `html.assets: cdn`; по умолчанию
(`inline`) внешних запросов нет вообще — см. [Отчёты](/ru/reporting/).

## Что enodia хранит

Только на вашей машине и только там, где вы укажете:

- файлы инвентаря, отчётов и истории, которые вы пишете через `-o`;
- кеш ответов endoflife.date/GitHub и разобранных баз CVE в системной
  директории кеша (`~/.cache/enodia`, `%LocalAppData%\enodia`) — его
  можно удалить в любой момент.

Больше ничего никуда не отправляется, и EpicMorg ничего не хранит.

## Этот сайт

Сайты enodia.sh, get.enodia.sh и docs.enodia.sh — не сама утилита
enodia — используют веб-аналитику Яндекс Метрики для подсчёта посещений.
