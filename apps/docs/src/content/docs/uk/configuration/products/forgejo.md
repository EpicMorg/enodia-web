Читає `GET /api/v1/version` — сумісний з Gitea API ендпоінт, який Forgejo
(форк Gitea) досі постачає за тим самим шляхом.

```yaml
targets:
  - id: forgejo-main
    product: forgejo
    address: https://forgejo.example.com
```

## Автентифікація

Необовʼязкова — за замовчуванням анонімний доступ. Екземпляр із
`REQUIRE_SIGNIN_VIEW = true` (справжня опція посилення захисту) натомість
відповідає `403`, і це обробляється так само, як виклик автентифікації
будь-якої іншої проби. Приймаються і `basic`, і `token-header` — точну
структуру полів кожного з них див. у
[Конфігурація → Облікові дані](/uk/configuration/#облікові-дані).

## Записувані поля

Лише `version` — ця проба не записує полів `extra`.

## Зіставлення з CVE

Зіставляється з NVD і БДУ ФСТЕК, якщо налаштовано [блок `cve:`](/uk/cve/).

## Резолвер життєвого циклу

`endoflife:forgejo`.
