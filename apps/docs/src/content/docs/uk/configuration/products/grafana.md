---

Читає версію з `GET /api/health`.

```yaml
targets:
  - id: grafana-main
    product: grafana
    address: https://grafana.example.com
```

## Автентифікація

Немає — підтверджено наживо, цей ендпоінт відповідає `200` з коректним
тілом навіть із неправильними обліковими даними Basic. Він існує для
перевірки працездатності балансувальником навантаження, а не як захищений
маршрут API, тож варіанту з обліковими даними тут немає.

## Записувані поля

- `version`
- `extra.commit`, `extra.database`

## Зіставлення з CVE

Зіставляється з NVD і БДУ ФСТЕК, якщо налаштовано [блок `cve:`](/uk/cve/).

## Резолвер життєвого циклу

`endoflife:grafana`.
