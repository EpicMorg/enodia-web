Читає `GET /api/v2.0/systeminfo`.

```yaml
targets:
  - id: harbor-main
    product: harbor
    address: https://harbor.example.com
```

## Автентифікація

Необовʼязкова. Підтверджено наживо на справжньому стеку `goharbor/harbor`
v2.12.2: на кожній наразі випущеній версії `harbor_version` повертається
взагалі без облікових даних — неправильні чи вигадані облікові дані
мовчки трактуються як анонімний доступ, а не отримують `401`; цей
ендпоінт ніколи не відхиляє запит повністю.

:::note[Стежте за змінами в upstream]
Власний код Harbor (станом на версію, на якій перевірено цю пробу) вже
закриває `harbor_version` перевіркою автентифікованого сеансу у своїй
основній гілці, ще не випущеній на момент написання, — тобто рухається до
майбутнього релізу, який вимагатиме облікових даних для цього поля. `basic`
тут уже підтримується на той випадок, коли це станеться:

```yaml
credentials:
  harbor-admin:
    kind: basic
    username: admin
    password: "${HARBOR_PASSWORD}"
```
:::

## Записувані поля

Лише `version` — ця проба не записує полів `extra`.

## Зіставлення з CVE

Зіставляється з NVD і БДУ ФСТЕК, якщо налаштовано [блок `cve:`](/uk/cve/).

## Резолвер життєвого циклу

`endoflife:harbor`.
