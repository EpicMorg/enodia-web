Читає версію, яку query-service Jaeger (компонент, що віддає UI, за
замовчуванням порт 16686) вбудовує у власний `index.html` через пошук і
заміну під час збирання, — окремого API версії немає.

```yaml
targets:
  - id: jaeger-main
    product: jaeger
    address: https://jaeger.example.com
```

## Автентифікація

Немає — Jaeger узагалі не має власної автентифікації. Розгортання за
зворотним проксі або SSO-шлюзом (oauth2-proxy — поширений реальний вибір)
відповідає перенаправленням у власний потік входу цього шлюзу замість HTML
Jaeger, що проявляється як власна помилка цієї проби «no JAEGER_VERSION
found», — це не те, що ця проба може подолати самостійно; така сама
прогалина була б у продукту з входом через форму.

## Записувані поля

Лише `version` — ця проба не записує полів `extra`.

## Зіставлення з CVE

Зіставляється з NVD, якщо налаштовано [блок `cve:`](/uk/cve/).

## Резолвер життєвого циклу

`endoflife:jaeger`.
