Сира TCP-проба на текстовому протоколі, а не HTTP — `address` має вигляд
`host` або `host:port`, без схеми. Якщо порт не вказано, використовується
`11211`. Надсилає `version` і читає однорядкову відповідь,
`VERSION 1.6.45`.

```yaml
targets:
  - id: memcached-01
    product: memcached
    address: cache.example.com:11211
```

## Автентифікація

Немає — текстовий протокол не має автентифікації. Сервер, запущений із
SASL (`-S`), говорить лише бінарним протоколом і відповідає на текстову
команду помилкою; це повідомляється як «не підтримується», а не
вгадується.

## Записувані поля

Лише `version` — напр. `1.6.45`. Ця проба не записує полів `extra`.

## Зіставлення з CVE

Зіставляється з NVD і БДУ ФСТЕК, якщо налаштовано [блок `cve:`](/uk/cve/).

## Резолвер життєвого циклу

`endoflife:memcached`.
