Сирий TCP-протокол, а не HTTP — `address` має вигляд `host` або
`host:port`, без схеми `https://`/`http://` (тут немає про що попереджати
через відсутню схему; див. [Конфігурація](/uk/configuration/#targets)).
Якщо порт не вказано, використовується `3306`.

Жоден запит не надсилається: MySQL сама повідомляє свою версію в
початковому пакеті рукостискання, до будь-якого кроку автентифікації, —
тож цій пробі ніколи не потрібні облікові дані, щоб її побачити.

```yaml
targets:
  - id: mysql-main
    product: mysql
    address: db.example.com:3306
```

## Автентифікація

Немає — версія зчитується безпосередньо з рукостискання, ще до моменту,
коли облікові дані взагалі мали б значення.

## MariaDB — інший продукт

MariaDB приховує свою справжню версію за префіксом `5.5.5-` для клієнтів
MySQL, старших за власну схему версій MariaDB, — це досі так на актуальному
образі MariaDB 10.11. `product: mysql`, спрямований на сервер MariaDB,
виявляє це й **навмисно завершується помилкою**, називаючи в повідомленні
справжню версію MariaDB, замість того щоб мовчки записати її як факт про
MySQL. Окремої проби `mariadb` поки немає — це жорстка зупинка, а не те, що
сьогодні можна обійти за допомогою
[узагальненої проби](/uk/configuration/products/generic/).

## Зіставлення з CVE

Зіставляється з NVD і БДУ ФСТЕК, якщо налаштовано [блок `cve:`](/uk/cve/).
