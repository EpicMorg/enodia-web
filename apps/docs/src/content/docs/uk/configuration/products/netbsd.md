---

Належить до сімейства [ідентифікації ОС через SSH](/uk/configuration/products/ssh-os-probes/),
але не до групи os-release — NetBSD узагалі не постачає жодного аналога
os-release, тому джерелом ідентичності натомість слугує `uname -sr`.
Спільний механізм, облікові дані та перевірку ключа хоста описано на
сторінці сімейства.

```yaml
targets:
  - id: netbsd-host
    product: netbsd
    address: host.example.com
    credentials: linux-host-ssh
```

Перевірено наживо через `vmactions/netbsd-vm` (іншого готового
попередньо встановленого образу для завантаження немає): `uname -sr` →
`"NetBSD 11.0"`, без жодного імені хоста — на відміну від `uname -a`, який ця
проба навмисно не використовує.

## Зіставлення з CVE

Не зіставляється — NVD записує рівні патчів у поле CPE, яке зіставник не читає, тож зіставлення лише за релізом позначило б повністю пропатчений хост усіма CVE, будь-коли виправленими в цьому релізі. Див. [Зіставлення з CVE](/uk/cve/#які-продукти-зіставляються).

## Резолвер життєвого циклу

`endoflife:netbsd`.
