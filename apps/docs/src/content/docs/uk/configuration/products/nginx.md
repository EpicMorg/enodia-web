Читає заголовок відповіді `Server`, який nginx встановлює в кожній відповіді.
Ендпоінта з версією немає: nginx (на відміну від REST API NGINX Plus)
анонімно більше нічого не надає — `/stub_status` модуля
`ngx_http_stub_status_module` віддає лічильники зʼєднань, але ніколи не версію.

```yaml
targets:
  - id: nginx-main
    product: nginx
    address: https://www.example.com
```

## Автентифікація

Немає — приймається будь-який код стану, оскільки nginx ставить власний
заголовок `Server` на сторінках помилок і перенаправленнях так само, як і
на `200`. Ціль, у якої `/` віддає 404 або стоїть за vhost із
Basic-автентифікацією, все одно нормально повідомляє версію. Обидва
випадки підтверджено наживо на реальних контейнерах `nginx:1.27.4`.

## `server_tokens off` прибирає версію

Власне налаштування посилення захисту nginx (поширене в продакшні) ставить
у заголовок просто `"nginx"` без жодної версії — це підтверджений продукт,
для якого нічого не лишається порівнювати з календарем життєвого циклу,
а не помилка парсера.

## Записувані поля

Лише `version` — ця проба не записує полів `extra`.

## Зіставлення з CVE

Зіставляється з NVD і БДУ ФСТЕК, якщо налаштовано [блок `cve:`](/uk/cve/).

## Резолвер життєвого циклу

`endoflife:nginx`.
