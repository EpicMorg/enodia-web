Читає версію, проставлену в нижньому колонтитулі `/oauth2/sign_in`.
oauth2-proxy узагалі не має JSON-ендпоінта версії — сторінка входу є єдиною
анонімною поверхнею (вона має відображатися ще до появи будь-якого
сеансу), і її стандартний шаблон записує версію прямо в текст нижнього
колонтитула.

```yaml
targets:
  - id: oauth2-proxy-main
    product: oauth2-proxy
    address: https://auth.example.com
```

## Автентифікація

Немає — підтверджено наживо на стандартній сторінці справжнього контейнера
`oauth2-proxy/oauth2-proxy`.

## Прапорець `--footer` може приховати версію

Власний прапорець `--footer` розгортання може замінити або приховати (`-`)
увесь цей рядок — анонімного запасного варіанта в такому разі немає. Це
підтверджений продукт, версію якого приховано власною конфігурацією
розгортання, а не помилка проби.

## Записувані поля

Лише `version` — ця проба не записує полів `extra`.

## Зіставлення з CVE

Зіставляється з NVD і БДУ ФСТЕК, якщо налаштовано [блок `cve:`](/uk/cve/).

## Резолвер життєвого циклу

немає, тому резолвінг натомість виконується через GitHub Releases: лише
останній опублікований тег, що не є пре-релізом, без дат eol/support/lts.
