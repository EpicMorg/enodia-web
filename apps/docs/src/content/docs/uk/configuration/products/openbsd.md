title: OpenBSD
description: Налаштування enodia для опитування OpenBSD через SSH.
---

Належить до сімейства [ідентифікації ОС через SSH](/uk/configuration/products/ssh-os-probes/),
але не до групи os-release — OpenBSD узагалі не постачає аналога os-release,
тому джерелом ідентичності натомість є `uname -sr`. Спільний механізм,
облікові дані та перевірку ключа хоста описано на сторінці сімейства.

```yaml
targets:
  - id: openbsd-host
    product: openbsd
    address: host.example.com
    credentials: linux-host-ssh
```

Перевірено наживо через `vmactions/openbsd-vm` (іншого готового
попередньо встановленого образу для завантаження не існує): `uname -sr` →
`"OpenBSD 7.9"`, узагалі без імені хоста — на відміну від `uname -a`, який
ця проба навмисно не використовує.

## Зіставлення з CVE

Не зіставляється — NVD записує рівні патчів у поле CPE, яке зіставник не читає, тож зіставлення лише за релізом позначило б повністю пропатчений хост усіма CVE, будь-коли виправленими в цьому релізі. Див. [Зіставлення з CVE](/uk/cve/#які-продукти-зіставляються).

## Резолвер життєвого циклу

`endoflife:openbsd`.
