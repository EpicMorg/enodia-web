Читає версію з `GET /api/system/status` (старіший псевдонім `/api/status`
відповідає ідентично, але ця проба завжди використовує поточний шлях).

```yaml
targets:
  - id: portainer-main
    product: portainer
    address: https://portainer.example.com
```

## Автентифікація

Немає — ендпоінт навмисно публічний і доступний ще до створення
обовʼязкового облікового запису адміністратора під час першого запуску.

## Записувані поля

- `version`
- `extra.instanceId`

## Зіставлення з CVE

Зіставляється з NVD і БДУ ФСТЕК, якщо налаштовано [блок `cve:`](/uk/cve/).

## Резолвер життєвого циклу

`github:portainer/portainer` — endoflife.date не має календаря Portainer
(підтверджено 404), тому резолвінг натомість виконується через GitHub
Releases: лише останній опублікований тег, що не є пре-релізом, без дат
eol/support/lts (GitHub не має позиції щодо політики життєвого циклу, лише
«який реліз останній»).
