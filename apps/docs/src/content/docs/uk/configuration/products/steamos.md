title: SteamOS

---

Належить до сімейства [ідентифікації ОС через SSH](/uk/configuration/products/ssh-os-probes/)
— спільний механізм, облікові дані та перевірку ключа хоста описано на
тій сторінці. Зіставляється за полем `ID` файлу `/etc/os-release`.

```yaml
targets:
  - id: steamos-host
    product: steamos
    address: host.example.com
    credentials: linux-host-ssh
```

Перевірено на справжньому знімку rootfs з ISO SteamOS 2 (на основі Debian,
кодова назва «brewmaster»): `ID=steamos`, `VERSION_ID="2"`. Очікується, що
SteamOS 3.x (на основі Arch, поточна ОС Steam Deck, кодова назва «holo»)
має той самий `ID=steamos` — власний брендинг Valve послідовний у всьому
переписаному варіанті, — але наживо це ще не підтверджено, лише для 2.x;
проста відповідність `ID=steamos` покриває обидві версії без потреби в
окремій обробці будь-якої з них.

## Зіставлення з CVE

Не зіставляється — CVE дистрибутива загального призначення є вразливостями пакетів, а номер релізу не показує, які пакети було виправлено відтоді. Див. [Зіставлення з CVE](/uk/cve/#які-продукти-зіставляються).

## Резолвер життєвого циклу

`endoflife:steamos`.
