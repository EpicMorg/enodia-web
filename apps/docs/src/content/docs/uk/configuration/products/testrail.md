Читає `GET /version.txt` — звичайний статичний файл, який TestRail постачає
у своєму веб-корені, а не відповідь REST API. Власний задокументований
REST API TestRail (`get_current_user` та подібні) потребує облікових даних
і взагалі не містить версії продукту, саме тому ця проба натомість читає
статичний файл.

```yaml
targets:
  - id: testrail-main
    product: testrail
    address: https://testrail.example.com
```

## Автентифікація

Немає — ендпоінт не приймає жодного виду облікових даних.

## Записувані поля

Лише `version` — обрізаний вміст файлу, точно в тому вигляді, в якому його
віддає сервер.

## Зіставлення з CVE

Зіставляється з NVD, якщо налаштовано [блок `cve:`](/uk/cve/).

## Резолвер життєвого циклу

Немає — endoflife.date не має календаря TestRail (підтверджено 404).
Поки що лише для інвентаризації.
