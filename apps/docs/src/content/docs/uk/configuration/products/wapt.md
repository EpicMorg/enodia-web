Читає `GET /ping` сервера WAPT (Tranquil IT), який той віддає без сеансу.

```yaml
targets:
  - id: wapt-main
    product: wapt
    address: https://wapt.example.com
```

## Яка версія повідомляється

`/ping` містить і `version` (`1.8.2`), і `git_hash`
(`1.8.2.7334-2d15afd9-debian-10-amd64`), що починається з повного номера
збірки. Коли цей номер збірки розширює `version`, повідомляється саме він
— `1.8.2.7334`, а не `1.8.2`. Підтверджено наживо на продакшн-сервері WAPT
1.8.2.

## Автентифікація

Немає — ендпоінт не приймає жодного виду облікових даних.

## Записувані поля

- `version` — напр. `1.8.2.7334`
- `extra.edition` — напр. `community`
- `extra.apiVersion` — напр. `v3`
- `extra.gitHash` — напр. `1.8.2.7334-2d15afd9-debian-10-amd64`

## Зіставлення з CVE

Зіставляється з NVD, якщо налаштовано [блок `cve:`](/uk/cve/).

З урахуванням редакції: власна редакція WAPT (`community`/`enterprise`)
уже збігається з термінами NVD і передається як є. Будь-яке інше значення
вважається невідомою редакцією, для якої зберігаються всі знахідки.

## Резолвер життєвого циклу

Немає — WAPT не має сторінки на endoflife.date (підтверджено 404), а теги
Tranquil IT на GitHub зупинилися на 1.5; релізи публікуються на їхньому
власному сайті, який жоден резолвер тут не читає. Поки що лише для
інвентаризації.
